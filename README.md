# Website Maker

A simple drag-and-drop website builder built with React + Vite.

## Features

- Add reusable landing page sections
- Drag sections to reorder them
- Edit section text and CTA labels
- Live visual preview on the right
- Export the page as HTML
- Change the brand colors

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build

```bash
npm run build
```

## Notes

This is a frontend-only website builder focused on a stylish landing page workflow. It is ready to extend with more blocks, drag handles, or a real backend.
